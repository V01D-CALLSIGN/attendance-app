# Attendance App

An iPhone app for managing classes, student rosters, daily attendance, and makeup sessions.

This is the first app I've built and put on an iPhone, which makes it a pretty special milestone for me.

## Features

- Guided setup for classes, students, and enrollments
- Home dashboard with upcoming classes and attendance summaries
- Weekly class calendar
- Searchable student directory and class rosters
- Present, absent, late, and makeup attendance statuses
- Makeup-credit tracking for missed sessions
- Local, on-device data storage

## Built With

- Swift
- SwiftUI
- Xcode
- Native Apple frameworks only—no third-party dependencies

## Running the App

1. Clone this repository.
2. Open `attendance-app.xcodeproj` in Xcode 26.6 or later.
3. Select an iPhone simulator or a connected iPhone running iOS 26.5 or later.
4. Press **Run**.

To install it on a physical iPhone, select your development team under **Signing & Capabilities** in Xcode before building.

## Project Status

This is a local-first prototype. App data is stored on the device, and the current version does not include accounts, cloud sync, messaging, or external calendar integration.
